# Elegant GRUB Theme Attribution

This is a minimal DreamingWrt adaptation of the
`forest / window / left / dark / 1080p` variant from
[vinceliuice/Elegant-grub2-themes](https://github.com/vinceliuice/Elegant-grub2-themes).

The upstream installer is intentionally not included or executed. DreamingWrt
ships only the runtime assets used by its GRUB menu:

- `background.jpg`
- `terminus-14.pf2`
- `select_e.png`, `select_c.png`, and `select_w.png`
- a DreamingWrt-specific `theme.txt`

Unused distro icons, logos, screen sizes, light variants, and generator scripts
are omitted. The upstream GPL-3.0 license is preserved as `LICENSE`.
